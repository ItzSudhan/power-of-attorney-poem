A Python program that writes one short poem about agency, "Power of Attorney", to `/output/entry.txt`. The poem follows agency as it passes from a grandmother to her grandchild, and from that grandchild to an AI agent.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
