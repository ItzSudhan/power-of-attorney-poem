A Python program that writes one short poem about agency, "Dual Control", to `/output/entry.txt`: a retired driving instructor, who spent his life not using the second brake, rides in a car that drives itself.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```
